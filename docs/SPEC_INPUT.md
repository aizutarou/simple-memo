## 1. 目的・背景

### 1.1 このアプリで達成したいこと（1〜3 文）

・趣味・個人開発の作業内容を、さっとメモして置けること
・**作業名ごとのフォルダ**でメモを分けて見返せること
・高級機能は不要、操作感はシンプル

### 1.2 作る理由・きっかけ（任意）

シンプルな使用感で、自分用の作業メモ置き場がほしい（厳密なタスク管理ではない）

### 1.3 「できた」と言える状態（成功の定義）

ブラウザで CRUD が問題なく動く

## 3. MVP の範囲

### 3.1 必ず入れたい機能（Must）

<!-- 番号付きで書いても、箇条書きでも OK -->

1. 作業名フォルダ（1 階層）の CRUD。削除時は **中のメモもまとめて削除**（案 B）+ **トースト Undo**
2. メモの作成・更新・削除
3. 削除 Undo（メモ・フォルダともトースト、同一セッション）— JSON エクスポートは MVP 外
4. IndexedDB で永続化
5. 新規メモ: フォルダ内＋はそのフォルダ固定 / トップ＋は前回フォルダ＋変更可

2. ゴミ箱（リロード後も復元）
3. JSON エクスポート
