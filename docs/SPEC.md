# Simple Memo — 仕様書（ドラフト v0.1）

最終更新: 2026-09-27  
ステータス: **レビュー待ち**

---

## 1. 目的

日常の短いメモを素早く書き、後から見返せる **最小構成** のアプリを作る。  
初回リリース（MVP）は「作る・読む・直す・消す」に集中し、機能を増やしすぎない。

## 2. 想定ユーザー

- 自分用のメモをブラウザ（または端末）に残したい人
- アカウント登録や複雑な整理より、**入力の速さ** を優先する人

## 3. MVP スコープ

### 3.1 含める（Must）

| ID | 機能 | 説明 |
|----|------|------|
| F-01 | メモ一覧 | 作成日時の新しい順（デフォルト）でタイトルまたは先頭行を表示 |
| F-02 | メモ作成 | タイトル（任意）+ 本文（必須） |
| F-03 | メモ詳細・編集 | 一覧から開き、内容を更新して保存 |
| F-04 | メモ削除 | 確認ダイアログ付きで削除 |
| F-05 | 永続化 | リロード・再起動後もメモが残る |
| F-06 | 空状態 | メモが 0 件のときの案内表示 |

### 3.2 含めない（MVP 外 — 将来候補）

- ユーザーアカウント / 同期 / 共有
- タグ・フォルダ・全文検索
- リッチテキスト・画像添付
- オフライン PWA（必要なら Phase 2）

## 4. 画面構成（案）

```
┌─────────────────────────────────────┐
│  Simple Memo          [+ 新規]      │  ← ヘッダ
├─────────────────────────────────────┤
│  □ メモタイトルまたは先頭行          │
│    2026/09/27 15:30                 │  ← 一覧
│  □ ...                              │
└─────────────────────────────────────┘

詳細 / 編集
┌─────────────────────────────────────┐
│  ← 戻る              [保存] [削除]  │
├─────────────────────────────────────┤
│  タイトル（任意）                    │
│  ─────────────────                  │
│  本文（複数行）                      │
└─────────────────────────────────────┘
```

## 5. データモデル（案）

```typescript
type Memo = {
  id: string;           // UUID v4
  title: string;        // 最大 200 文字、空可
  body: string;         // 最大 10_000 文字、必須（空白のみは不可）
  createdAt: string;    // ISO 8601
  updatedAt: string;    // ISO 8601
};
```

**一覧表示ルール**

- `title` が空なら `body` の先頭 1 行（最大 80 文字）をリスト表示に使う

## 6. 技術スタック（提案 — 要合意）

| レイヤ | 提案 | 理由 |
|--------|------|------|
| フロント | React + TypeScript + Vite | 学習・保守のバランスが良い |
| スタイル | CSS Modules または Tailwind | 小規模 UI 向け |
| 永続化（MVP） | ブラウザ `localStorage` | バックエンド不要で最短 |
| 永続化（Phase 2 候補） | SQLite + 軽量 API | 複数端末・バックアップ |

**MVP は localStorage のみ** とし、後から API に差し替えやすいよう `MemoRepository` インターフェースで抽象化する。

## 7. 非機能要件（MVP）

- 一覧・保存・削除は **300ms 以内** に UI が反応（体感）
- 日本語入力（IME）で問題なく編集できる
- 主要ブラウザ: Chrome / Safari / Firefox の最新 2 バージョン

## 8. 受け入れ基準（例）

- [ ] 新規メモを作成し、一覧に表示される
- [ ] 既存メモを編集し、更新日時が変わる
- [ ] メモを削除し、一覧から消える
- [ ] ページをリロードしてもデータが残る
- [ ] 本文が空（または空白のみ）のメモは保存できない

## 9. 未決定事項（レビューで決めたい）

1. **プラットフォーム**: Web のみ / 将来ネイティブも視野に入れるか
2. **永続化**: MVP は localStorage でよいか、最初からサーバー付きにするか
3. **デザイン**: ライトのみ / ダークモード対応
4. **ソート**: 更新日時順の切り替えを MVP に入れるか
5. **既存 `memoTool` との関係**: 完全に別プロジェクトとして進める（本リポジトリ）
