# Simple Memo — 仕様書 v0.3.1

最終更新: 2026-09-27  
ステータス: **MVP 実装開始可**（Phase 0 完了。デザイン・CI は Phase 3〜4）

---

## 1. コンセプト

趣味・個人開発の **作業メモ** を、考えずに短く書き、**作業名ごとのフォルダ** で見返せる **自分専用** の Web アプリ。

- フォルダ名 = **作業名・プロジェクト名**（例: `simple-memo`、`ゲーム制作`）
- **タスク管理アプリではない**（期限・カンバン・完了チェックは持たない）
- **日付見出しでのグループ表示はしない**（一覧はフラット + 作成日時降順）
- 1 メモ = **1 フォルダ** に所属（ネストフォルダは MVP 外）

## 2. 想定ユーザー・環境

- **利用者**: 自分だけ（MVP）
- **主な端末**: スマートフォン（SP）ブラウザ中心
- アカウント登録・同期・共有は MVP 外

## 3. MVP スコープ

### 3.1 含める（Must）

| ID | 機能 | 説明 |
|----|------|------|
| F-01 | フォルダ CRUD | **作業名**で 1 階層。常に **「あとで振り分け」** フォルダ 1 つ（削除・改名不可） |
| F-02 | フォルダ削除 | 確認後 **フォルダと中のメモをまとめて物理削除**（取り消し不可） |
| F-03 | メモ CRUD | タイトル（任意）+ 本文（必須）。必ず 1 フォルダに所属 |
| F-04 | メモ一覧 | フォルダ内、**作成日時降順**、日付グループなし |
| F-05 | メモ編集 | **オートセーブ**（debounce）。フォルダ変更可 |
| F-06 | メモ削除 | 確認後 **物理削除**（取り消し不可） |
| F-07 | 永続化 | **IndexedDB**（Dexie.js 想定） |
| F-08 | 新規メモ（フォルダ内） | そのフォルダに固定で新規 |
| F-09 | 新規メモ | フォルダ内、または **「あとで振り分け」** へ。前回フォルダがなければ同フォルダが初期値 |
| F-10 | 空状態 | フォルダ / メモ 0 件の案内 |
| F-11 | 検索 | **フォルダ名**、**メモ**（タイトル・本文）の部分一致。メモは更新日時降順 |

**削除**

- メモ・フォルダとも **確認シートのあと即削除**（Undo・ゴミ箱なし）

### 3.2 含めない（MVP 外）

- 日付単位のグループ見出し
- ユーザーアカウント / クラウド同期 / 共有
- タグ、ネストフォルダ
- ゴミ箱（リロード後も復元）
- JSON エクスポート / インポート
- 完了チェック ☐、期限・リマインダー
- リッチテキスト・画像添付
- PWA 専用対応

### 3.3 将来候補（Phase 2）

- ゴミ箱・JSON バックアップ
- 複数端末同期（API / BaaS）
- フォルダの色・アイコン
- デプロイ（GitHub Pages / Vercel）

## 5. データモデル

```typescript
type Folder = {
  id: string;
  name: string;           // 作業名、最大 100 文字
  createdAt: string;
  updatedAt: string;
  isDefault?: boolean;    // 非推奨（旧データ互換のみ）
};

type Memo = {
  id: string;
  folderId: string;
  title: string;
  body: string;
  createdAt: string;      // 一覧ソートキー（降順）
  updatedAt: string;
  deletedAt?: string;     // 非推奨（旧データ互換のみ）
};
```

**一覧表示**

- `title` が空 → `body` 先頭 1 行（最大 80 文字）
- 各行に **作成日時** を表示（記録日の確認用。グループ分けはしない）

**フォルダ削除**

- フォルダ削除: 確認文で **メモ件数** を表示 → OK で **フォルダ + 配下メモを物理削除**

## 6. 技術スタック（確定）

| レイヤ | MVP |
|--------|-----|
| フロント | **React + TypeScript + Vite** |
| 永続化 | **IndexedDB（Dexie.js）** |
| 前回フォルダ ID | `localStorage` 1 キー（補助のみ） |
| スタイル | 未決（Phase 1 で 1 案選定） |
| バックエンド | なし |

**Repository**: `FolderRepository` / `MemoRepository` を interface で抽象化。

## 7. 非機能要件

- オートセーブ: debounce **300〜500ms**（調整可）
- 日本語 IME 対応
- モバイル Safari / Chrome

## 8. 受け入れ基準

- [ ] 作業名フォルダを CRUD できる
- [ ] フォルダ削除で確認後、中のメモもまとめて消える
- [ ] フォルダ内メモが **作成日降順** で表示される（日付グループなし）
- [ ] オートセーブで編集内容が残る
- [ ] メモ削除は確認後に確定する
- [ ] リロード後も IndexedDB から復元される
- [ ] 本文空白のみは保存されない
