# アプリ名の検討

表示名は `src/config/branding.ts` の `APP_DISPLAY_NAME` で変更できます（`index.html` の `<title>` も合わせて更新してください）。

## コンセプトのおさらい

- 趣味・個人開発の **作業メモ**
- **作業名ごとのフォルダ** で整理
- タスク管理ほど複雑にしない

## 候補

| 名前 | 印象 | メモ |
|------|------|------|
| **Simple Memo**（現状） | 英語・汎用 | リポジトリ名と一致。説明が必要 |
| **わたしの作業メモ**（採用） | 日本語・親しみ | 個人向けでポップなトーン |
| **個人作業メモ** | 日本語 | 個人の作業ログであることが明確 |
| **作業メモ** | 日本語・直球 | 用途が一目で分かる |
| **LogFolder** | 英語・開発者向け | フォルダ + ログ感 |
| **進捗メモ** | 日本語 | 「進捗確認」に近い |
| **Project Scratch** | 英語 | 下書き・走り書き感 |
| **メモ置場** | カジュアル | 軽いトーン |

## 決め方のヒント

1. スマホのホーム画面に追加したとき **短い名前** がよい（4〜6 文字程度）
2. App Store 等は今回なし → **自分が毎日見る文字** を優先
3. リポジトリ名 `simple-memo` は **変更不要**（表示名だけ変えてよい）

## 次のアクション

好みの名前（または新案）を決めたら、`APP_DISPLAY_NAME` と `index.html` の title を更新する。
